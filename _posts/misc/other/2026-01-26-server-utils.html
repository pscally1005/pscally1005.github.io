--- layout: post title: Minecraft Server Utils date: 2026-01-26 00:00:00 -0500 categories: - Misc. - Other Projects showPercentage: no permalink: /misc/server-utils image: /assets/Misc/Other/mc.jpg tags: - minecraft - java code - video games --- Minecraft Server-Utils is a set of useful Minecraft server commands that my brother and I developed for our Minecraft server.

Its main functionality includes commands to replace stairs, slabs, and more with other types (ex: oak to cobblestone), while preserving the orientation of the block. This is as opposed to WorldEdit, which will always reset all blocks back to a default orientation. The plugin is also compatible with the wooden axe selection tool.

Additionally, the plugin also contains methods for randomly filling chests with items and saving WorldEdit distributions. The plugin is available on GitHub below.
