Description: Yesterday I made <a href='/recipes/yellow-rice'>Anti-Inflammatory Yellow(ish) Rice</a>, but today I'm making a simple, non-traditional risotto using healthier <a href='/misc/grains#brown-rice'>brown rice</a> instead of <a href='/misc/grains#white-rice'>white arborio rice</a>. <a href='/misc/grains#brown-rice'>Brown rice</a> has more <a href='/misc/protein'>protein</a>, <a href='/misc/fiber'>fiber</a>, and <a href='/misc/nutrient-alphabet'>micronutrients</a>, like <a href='/misc/nutrient-alphabet'>vitamins</a> <a href='/misc/nutrient-alphabet#T'>B1</a>, <a href='/misc/nutrient-alphabet#R'>B2</a>, <a href='/misc/nutrient-alphabet#N'>B3</a>, <a href='/misc/nutrient-alphabet#B'>B6</a>, <a href='/misc/nutrient-alphabet#E'>E</a>, and <a href='/misc/nutrient-alphabet#K'>K</a>, as well as <a href='/misc/nutrient-alphabet#C'>copper</a>, <a href='/misc/magnesium'>magnesium</a>, <a href='/misc/nutrient-alphabet#M'>manganese</a>, <a href='/misc/phosphorus'>phosphorus</a>, <a href='/misc/potassium'>potassium</a>, <a href='/misc/nutrient-alphabet#S'>selenium</a>, and <a href='/misc/nutrient-alphabet#Z'>zinc</a>. This is a simple base <a href='/recipes/sides'>side</a> dish that can have whatever spices you want mixed into it. Or mix in some <a href='/misc/meat'>meat</a> and <a href='/misc/veggies'>vegetables</a> to make it a complete meal. <a href='/misc/veggies#butternut-squash'>Butternut squash</a> is great in risotto, as it melts right into it, making it creamier without the need for <a href='/misc/dairy#butter'>butter</a>. Check out my <a href='/recipes/butternut-squash-risotto'>Butternut Squash RisOATto</a> for a risotto recipe using <a href='/misc/grains#oats'>rolled oats</a>!
Instructions:
- In a medium pan over medium heat, add <a href='/misc/grains#brown-rice'>rice</a> and toast until fragrant, about 3-5 minutes

- Add in a little bit of your broth and stir. Cook until most of the water has evaporated. Repeat until you have no broth left and the <a href='/misc/grains#brown-rice'>rice</a> is al dente, about 30 minutes. You don't need to stir the <a href='/misc/grains#brown-rice'>rice</a> constantly, only every minute or so

- Stir in <a href='/misc/dairy#grated-cheese'>grated cheese</a> and <a href='/misc/fruit#lemon-juice'>lemon juice</a> until creamy. Add in any spices you desire
