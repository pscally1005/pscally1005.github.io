Description: I came up with this idea, as it rhymes with PB&J, and serves as a tastier and healthier option for the classic sandwich. The added proteins in the <a href='/recipes/natural-peanut-butter'>peanut butter</a> and jelly serve to make the sandwich more filling, and without the <a href='/misc/hidden-sugar'>added sugars</a> of typical jelly or jam. To make it even better, serve this on <a href='/recipes/ww-bread'>100% Whole Wheat Bread</a>.
Instructions:
- For the <a href='/misc/nuts#peanuts'>peanut butter</a> - in a <a href='https://amzn.to/4zyFnzN'>small bowl</a> or glass, combine <a href='/misc/nuts#peanuts'>peanut butter</a>, <a href='https://amzn.to/4sgDH9S'>powdered peanut butter</a>, and <a href='/misc/dairy#skim-milk'>milk</a>

- For the jelly - In a <a href='https://amzn.to/4zyFnzN'>small bowl</a>, mash the <a href='/misc/fruit#banana'>banana</a>. Mix with the <a href='/misc/dairy#whey'>protein powder</a> and cinnamon.  Add some sweetner if you like (1/4 tsp, 1.25 g <a href='https://amzn.to/3SqwsMO'>liquid monk fruit</a> or <a href='https://amzn.to/45wOzIv'>stevia</a>)

- Spread <a href='/misc/fruit#banana'>banana</a> spread on one slice of <a href='/recipes/bread'>bread</a>. Spread the <a href='/misc/nuts#peanuts'>peanut butter</a> on the other.
