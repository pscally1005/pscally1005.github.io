Description: These <a href='/misc/fiber'>high fiber</a>, <a href='/misc/hidden-sugar'>sugar free</a> pumpkin truffles feature my newly homemade <a href='/recipes/condensed-milk'>Sugar Free Sweetened Condensed Milk</a>. Mix that with some <a href='/recipes/pumpkin-puree'>pumpkin puree</a>, pumpkin spices, and <a href='/misc/fiber'>high fiber</a> flours, and you'll have yourself a quick and easy, <a href='/misc/fiber'>high fiber</a> snack!
Instructions:
- Add all ingredients to a <a href='https://amzn.to/4zyFnzN'>large bowl</a>. Mix together with a <a href='https://amzn.to/40F2aK0'>silicone spatula</a> to form a dough.
- <img src='/assets/Food/Finger Food/Pumpkin Truffle/bowl.jpg' alt='' class='instruction-image'>

- Roll into 60 equally sized balls, about <b>1 1/2 tbsp</b> or <b>20 g</b> each.
- <img src='/assets/Food/Finger Food/Pumpkin Truffle/plate.jpg' alt='' class='instruction-image'>

- Optionally, use a toothpick to make ridges on the side to make them look like pumpkins. Garnish with a chocolate chip on top.
- <img src='/assets/Food/Finger Food/Pumpkin Truffle/cover.jpg' alt='' class='instruction-image'>
Notes:
- If you were to make <a href='#recipe'>this recipe</a> using a standard can of <a href='https://link.amazon/B0gAsxJJN'>storebought condensed milk</a>, it would nearly double the <a href='/misc/calories'>calories</a> and add over 3 g of <a href='/misc/hidden-sugar'>added sugar</a> per truffle. While this difference may not look like a lot, this is <b>per truffle</b>, so it can add up quickly if you have multiple.
