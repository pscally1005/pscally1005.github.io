Description: Today I'm making a <a href='/recipes/guacamole'>guacamole</a> inspired dip, but with <a href='/misc/dairy#yogurt'>Greek yogurt</a> as the base instead of <a href='/misc/fruit#avocado'>avocados</a>. Not because <a href='/misc/fruit#avocado'>avocados</a> are "higher in <a href='/misc/fats'>fat</a>" or "higher in <a href='/misc/calories'>calories</a>", or because <a href='/misc/dairy#yogurt'>yogurt</a> is "higher in <a href='/misc/protein'>protein</a>". But because dammit I want <a href='/recipes/guacamole'>guac</a> and all I have right now is <a href='/misc/dairy#yogurt'>yogurt</a>. If there's a will, there's a way. For a more standard <a href='/recipes/guacamole'>guac</a> recipe, check out my <a href='/recipes/guacamole'>Holy Guacamole</a>!
Instructions:
- Finely dice an <a href='/misc/veggies#onion'>onion</a>, and add to a <a href='https://amzn.to/4zyFnzN'>medium bowl</a> with <a href='/misc/dairy#yogurt'>yogurt</a>, <a href='/misc/veggies#garlic'>minced garlic</a>, <a href='/misc/fruit#lime-juice'>lime juice</a>, paprika, chili powder, cumin, salt, and pepper. Mix together with a <a href='https://amzn.to/40F2aK0'>silicone spatula</a> until fully combined.
