Description: |
  Did you know that German Chocolate Cake isn't German?  It was named after American baker Samuel German, who created Baker's German Sweet Chocolate and the Baker's Chocolate Company in 1852. In 1957, Lucy Clay then submitted a cake recipe in the Dallas Morning News, titled "German's <a href='/recipes/chocolate-cake'>Chocolate Cake</a>". The apostrophe was eventually dropped, and German Chocolate Cake was born.<br><br>

  A <a href='https://tastesbetterfromscratch.com/german-chocolate-cake/#wprm-recipe-container-10369'>traditional German chocolate cake</a> is a chocolate cake with a chocolate frosting, and a filling of <a href='/misc/nuts#coconut'>coconut</a> and <a href='/misc/nuts#pecans'>pecans</a>. While delicious, it is filled with not so healthful ingredients, such as <a href='/misc/hidden-sugar'>white and brown sugar</a>, <a href='/misc/dairy#butter'>butter</a> and <a href='/misc/olive-oil'>oil</a>, <a href='/misc/grains#white-wheat'>refined flour</a>, and <a href='https://amzn.to/4xzQXZC'>sweetened coconut</a>.<br><br>

  On the other hand, this cake here is <a href='/misc/celiac'>gluten free</a>, vegan, and <a href='/misc/hidden-sugar'>sugar free</a>. There's no <a href='/misc/grains#white-wheat'>refined flour</a>, <a href='/misc/fats'>added fats</a>, or <a href='/misc/hidden-sugar'>added sugars</a>.<br><br>

  Instead, it gets plenty of <a href='/misc/fats'>healthy fats</a> from <a href='/misc/nuts#almonds'>almond flour</a> and chopped <a href='/misc/nuts#pecans'>pecans</a>. It gets <a href='/misc/carbs'>whole food carbohydrates</a> from <a href='/misc/grains#oats'>oat flour</a> without the need for <a href='/misc/grains#white-wheat'>white flour</a>, and the <a href='/recipes/sugar-free-syrup'>sugar free syrup</a> provides <a href='/misc/five-tastes#sweet'>sweetness</a> for significantly fewer <a href='/misc/calories'>calories</a>, without any <a href='/misc/hidden-sugar'>added sugar</a>.<br><br>

  This healthy, <a href='/misc/processed-foods'>whole foods</a> cake uses no <a href='/misc/dairy#butter'>butter</a>, <a href='/misc/meat#eggs'>eggs</a>, or <a href='/misc/dairy#skim-milk'>milk</a>, making it vegan, while still being creamy, moist, and delicious. No one would know that you're serving them a healthy vegan and <a href='/misc/celiac'>gluten free</a> cake full of <a href='/misc/processed-foods'>whole food</a> ingredients instead of refined junk.
Instructions:
- |
  <b>Cake</b><br>
  Preheat your oven to 350F. Line 2 <a href='https://amzn.to/4mxxkxl'>9" cake pans</a> with parchment paper, and <a href='https://amzn.to/3Hdg0gk'>lightly grease</a> them with <a href='/misc/olive-oil'>oil</a>.

- Whisk together the dry ingredients in a <a href='https://amzn.to/4zyFnzN'>large bowl</a> - <a href='/misc/grains#oats'>oat flour</a>, <a href='/misc/nuts#almonds'>almond flour</a>, <a href='/misc/chocolate-benefits'>cocoa powder</a>, baking powder, baking soda, and salt.

- In a separate <a href='https://amzn.to/4zyFnzN'>large bowl</a>, whisk together the wet ingredients - <a href='/misc/fruit#apple'>applesauce</a>, <a href='/recipes/sugar-free-syrup'>sugar free syrup</a>, <a href='/misc/dairy#almond-milk'>almond milk</a>, <a href='/misc/apple-cider-vinegar'>apple cider vinegar</a>, and <a href='https://amzn.to/43MkDqr'>vanilla extract</a>.

- Add the dry ingredients into the wet, and mix until just fully combined with a <a href='https://amzn.to/40F2aK0'>silicone spatula</a>.
- <img src='/assets/Food/Healthier Dessert/German/bowl.jpg' alt='' class='instruction-image'>

- Evenly divide the cake batter across the 2 pans, about 720 g or 3 cups into each pan.
- <img src='/assets/Food/Healthier Dessert/German/raw.jpg' alt='' class='instruction-image'>

- Bake the cakes at 350F for about 40 minutes. The cakes should be slightly firm in the center, where a toothpick to the middle comes out nearly clean, and the <a href='https://amzn.to/4kmobG2'>internal temperature</a> is around <a href='https://amzn.to/4kmobG2'>200F</a>. Let the cakes cool in the pan for 10 minutes before transferring to a <a href='https://amzn.to/4qQNmn2'>wire rack</a>. Allow them to cool completely, at least 1 hour in the fridge.
- <img src='/assets/Food/Healthier Dessert/German/baked.jpg' alt='' class='instruction-image'>

- |
  <b>Frosting</b><br>
  Add <a href='/misc/nuts#almonds'>almond butter</a>, <a href='/misc/chocolate-benefits'>cocoa powder</a>, <a href='https://amzn.to/43MkDqr'>vanilla extract</a>, and <a href='/recipes/sugar-free-syrup'>sugar free syrup</a> to a <a href='https://amzn.to/4zyFnzN'>medium bowl</a>. Mix until fully combined with a <a href='https://amzn.to/40F2aK0'>silicone spatula</a>. Set your <a href='/recipes/protein-frosting'>frosting</a> aside.
- <img src='/assets/Food/Healthier Dessert/German/frosting.jpg' alt='' class='instruction-image'>

- |
  <b>Filling</b><br>
  Add chopped <a href='/misc/nuts#pecans'>pecans</a> and <a href='/misc/nuts#coconut'>coconut flakes</a> to a dry pan over medium heat. Toast for about 3 minutes, or until fragrant and lightly browned.
- <img src='/assets/Food/Healthier Dessert/German/toasted.jpg' alt='' class='instruction-image'>

- Combine the toasted <a href='/misc/nuts#pecans'>pecans</a> and <a href='/misc/nuts#coconut'>coconut flakes</a> with <a href='https://amzn.to/43MkDqr'>vanilla extract</a> and <a href='/recipes/sugar-free-syrup'>sugar free syrup</a> in a <a href='https://amzn.to/4zyFnzN'>medium bowl</a>. Set the filling aside.
- <img src='/assets/Food/Healthier Dessert/German/filling.jpg' alt='' class='instruction-image'>

- |
  <b>Assemble</b><br>
  Place your first cake layer upside down on the plate, so the flatter side faces up.
- <img src='/assets/Food/Healthier Dessert/German/layer1.jpg' alt='' class='instruction-image'>

- Spread about 2/3 of your filling mixture (~230 g or 1 cup) onto the bottom (now top) of the first layer.
- <img src='/assets/Food/Healthier Dessert/German/filled.jpg' alt='' class='instruction-image'>

- Add the second layer on top, with the "bottom" (flat side) facing up.
- <img src='/assets/Food/Healthier Dessert/German/layer2.jpg' alt='' class='instruction-image'>

- Carefully frost the top and sides of the cake. Add your remaining filling mixture (~115 g or 1/2 cup) on top of the frosting on top of the cake. Optionally garnish with more <a href='/misc/nuts#coconut'>coconut flakes</a>.
- <img src='/assets/Food/Healthier Dessert/German/topped.jpg' alt='' class='instruction-image'>
Notes:
- I only baked a half batch to test the recipe, which is why the photos in the assembly of the cake are of half a cake.

- <a href='/misc/nuts#pecans'>Pecans</a> are traditional in German Chocolate Cake, but almost nothing about this cake is traditional.  So go for <a href='/misc/nuts#walnuts'>walnuts</a> or something else if that's all you have.

- |
  I'm using <a href='/recipes/sugar-free-syrup'>sugar free syrup</a> to make this cake <a href='/misc/hidden-sugar'>sugar-free</a>, but you can also use <a href='/misc/natural-sweeteners#honey'>honey</a>, <a href='/misc/natural-sweeteners#maple-syrup'>maple syrup</a>, or <a href='/misc/natural-sweeteners#agave'>agave</a>.<br><br>

  Note that since this cake contains a significant amount of sweetener, using <a href='/misc/natural-sweeteners#honey'>honey</a>, <a href='/misc/natural-sweeteners#maple-syrup'>maple syrup</a>, or <a href='/misc/natural-sweeteners#agave'>agave</a> will add about 100 <a href='/misc/calories'>calories</a> and 30 g of <a href='/misc/hidden-sugar'>added sugar</a> per slice.

- |
  Please note though, that while this cake contains healthy ingredients, it is not a <a href='/misc/calories'>low calorie</a> <a href='/recipes/healthier-dessert'>dessert</a>. Each of the 16 slices contains roughly 250 <a href='/misc/calories'>calories</a>. For reference, that's less about 60% lower in <a href='/misc/calories'>calories</a> per slice as compared to a <a href='https://tastesbetterfromscratch.com/german-chocolate-cake/#wprm-recipe-container-10369'>traditional German Chocolate Cake</a>.<br><br>

  While the <a href='/misc/calories'>calories</a> are much lower, this is still relatively <a href='/misc/calories'>high-calorie</a> since the slices are small.  The difference here is that the <a href='/misc/calories'>calories</a> come from much better sources.<br><br>

  Instead of being filled with <a href='/misc/fats'>saturated fat</a>, empty <a href='/misc/carbs'>starch</a>, and <a href='/misc/hidden-sugar'>added sugar</a>, <a href='#recipe'>my cake here</a> has more <a href='/misc/fiber'>fiber</a>, <a href='/misc/protein'>protein</a>, <a href='/misc/nutrient-alphabet'>vitamins</a>, <a href='/misc/nutrient-alphabet'>minerals</a>, and <a href='/misc/phytochemicals'>antioxidants</a> without the <a href='/misc/hidden-sugar'>refined sugar</a>, <a href='/misc/grains#white-wheat'>flour</a>, or <a href='/misc/dairy#butter'>butter</a>.  Something can be healthy and <a href='/misc/calories'>high calorie</a> (this cake), or unhealthy and <a href='/misc/calories'>low calorie</a> (ex: jelly beans).<br><br>

  So while you should enjoy this cake, please consume it in moderation, since it is still quite rich in <a href='/misc/fats'>fat</a>, total sugar, and <a href='/misc/calories'>calories</a>, especially if you opt for <a href='/misc/natural-sweeteners#honey'>honey</a> (or <a href='/misc/natural-sweeteners#maple-syrup'>maple syrup</a> or <a href='/misc/natural-sweeteners#agave'>agave</a>) in place of the <a href='/recipes/sugar-free-syrup'>sugar free syrup</a>.
