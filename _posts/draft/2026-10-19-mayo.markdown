Description: <a href='/misc/fake-healthy-foods#dips'>Mayo</a> is basically an emulsion of <a href='/misc/olive-oil'>oil</a> and <a href='/misc/meat#eggs'>egg yolk</a>, so it's inherently very high in <a href='/misc/fats'>fat</a> and <a href='/misc/calories'>calories</a>. Using <a href='/misc/olive-oil'>extra virgin olive oil</a> at least replaces the typical <a href='/misc/fake-healthy-foods#seed-oil'>refined oil</a> with a source of predominantly <a href='/misc/fats'>monounsaturated fat</a>. <a href='/misc/olive-oil'>EVOO</a> also gives the <a href='/misc/fake-healthy-foods#dips'>mayo</a> a more pronounced flavor, which can be a plus if you like <a href='/misc/olive-oil'>olive oil</a>. It's still an extremely <a href='/misc/calories'>calorie-dense</a> spread, though, so use it in moderation like regular <a href='/misc/fake-healthy-foods#dips'>mayo</a>.
Instructions:
- Add <a href='/misc/meat#eggs'>egg yolks</a>, water, mustard, <a href='/misc/fruit#lemon-juice'>lemon juice</a>, salt, and <a href='/misc/olive-oil'>oil</a> to a tall and narrow cup or jar. Let everything sit for about 30 seconds.

- Lower an <a href='https://amzn.to/3VHhgMM'>immersion blender</a> all the way to the bottom of the cup. Blend without moving it up for around 15 seconds, or until it starts to thicken and emulsify.

- Slowly raise the <a href='https://amzn.to/3VHhgMM'>immersion blender</a> as you blend to incorporate all the <a href='/misc/olive-oil'>oil</a>. It should roughly double in volume and be thick and creamy, with everything fully incorporated.

- Refrigerate in an airtight container and use within 3–4 days. Because this recipe contains raw <a href='/misc/meat#eggs'>egg yolks</a>, keep refrigerated and discard if left at room temperature for more than 2 hours.
Notes:
- The cup should be just barely wider than your <a href='https://amzn.to/3VHhgMM'>immersion blender</a>, and tall enough to fully submerge it.

- For a more neutral flavor, use avocado oil. For a more standard <a href='/misc/fake-healthy-foods#dips'>mayo</a>, use <a href='/misc/fake-healthy-foods#seed-oil'>canola oil</a>. For the lolz, use <a href='/misc/slow-cooker-chicken'>chicken fat</a>.

- <a href='#recipe'>This recipe</a> makes <b>340 g</b> (approximately <b>1 cup + 9 tbsp</b>) of <a href='#recipe'>homemade mayo</a>.

- Use this as a 1:1 substitute for storebought <a href='/misc/fake-healthy-foods#dips'>mayo</a> in all applications, whether it be for the basis of a sauce, or as a binder for your potato salad, <a href='/recipes/hummus-coleslaw'>coleslaw</a>, or tuna salad!

- <a href='/misc/fake-healthy-foods#dips'>Mayo</a> is the basis of many popular <a href='/recipes/savory-sauces'>sauces</a> and <a href='/misc/fake-healthy-foods#salad-dressing'>dressings</a>, whether you know it or like it. <a href='/recipes/no-honey-mustard'>Honey mustard dressing, <a href='/recipes/greek-yogurt-caesar-dressing'>Caesar</a>, Thousand Island, Russian dressing, <a href='#aioli'>aioli</a>, tartar sauce, secret sauce, burger sauce. Whatever you want to call it, it probably uses <a href='/misc/fake-healthy-foods#dips'>mayo</a> as the basis.
