Description: <a href='https://amzn.to/3FduH2z'>RxBars</a> are a rare breed, being a healthy packaged snack with minimal ingredients and delicious flavor. There's one problem though - their price.  At nearly $2 a bar, <a href='https://amzn.to/3FduH2z'>RxBars</a> have quite a hefty price tag.  In comparison, my <a href='/copycat'>copycat</a> version costs just $0.51, almost a quarter of the price. All with the same ingredients, <a href='/misc/calories'>calories</a>, <a href='/misc/protein'>protein</a>, <a href='/misc/fats'>fat</a>, <a href='/misc/carbs'>carbs</a>, and <a href='/misc/fiber'>fiber</a>.  Plus they take only 10 minutes to make a batch of 9 bars!  If you enjoy <a href='/copycat'>copycat</a> protein bar recipes, also see my <a href='/recipes/copycat-quest-bars'>Copycat Quest Protein Bars</a> and <a href='/recipes/copycat-barebell'>Copycat Barebell Protein Bars</a>
Instructions:
- In a <a href='https://amzn.to/4q0AUjI'>food processor</a>, chop the <a href='/misc/nuts'>nuts</a> until finely ground, about 30 seconds. Don't over blend, or you'll end up with <a href='/recipes/natural-peanut-butter'>nut butter</a>

- Add in the <a href='/misc/dairy#whey'>protein powder</a>, <a href='/misc/chocolate-benefits'>cocoa powder</a>, vanilla, and salt. Blend for 30 seconds to fully incorporate

- Add in the <a href='/misc/fruit#dates'>dates</a>, hold down your <a href='https://amzn.to/4q0AUjI'>food processor</a>, and blend until fully chopped. Thin out with <a href='/misc/dairy#almond-milk'>almond milk</a> as needed
- <img src='/assets/Food/Protein Powder/RX/processor.jpg' alt='' class='instruction-image'>

- Line a <a href='https://amzn.to/3YY2H9q'>9" square baking pan</a> with parchment paper. Using kitchen gloves to prevent sticking. evenly press the dough into all edges of the pan
- <img src='/assets/Food/Protein Powder/RX/pan.jpg' alt='' class='instruction-image'>

- Cut into 9 protein bars. Store leftovers in an airtight container with a piece of parchment paper between each one to prevent sticking
- <img src='/assets/Food/Protein Powder/RX/stacked.jpg' alt='' class='instruction-image'>
Notes:
- I've gone with <a href='/misc/nuts#almonds'>almonds</a> and <a href='/misc/nuts#cashews'>cashews</a> here, but any <a href='/misc/nuts'>nuts</a> or <a href='/misc/seeds'>seeds</a> will do, such as <a href='/misc/nuts#peanuts'>peanuts</a>, <a href='/misc/nuts#pistachios'>pistachios</a>, <a href='/misc/nuts#walnuts'>walnuts</a>, <a href='/misc/seeds#pumpkin-seeds'>pumpkin seeds</a>, or <a href='/misc/seeds#sunflower-seeds'>sunflower seeds</a>.  Just use 1 cup (120 g) total of <a href='/misc/nuts'>nuts</a>/<a href='/misc/seeds'>seeds</a>, and mix and match how you feel

- You can even use <a href='/recipes/natural-peanut-butter'>natural nut butter</a> (1/2 cup, 128 g) instead of chopped <a href='/misc/nuts'>nuts</a>

- I'm using vanilla <a href='/misc/dairy#whey'>whey</a> today, but you can use chocolate for a double chocolate <a href='https://amzn.to/3FduH2z'>RxBar</a>.  If you prefer it less sweet, opt for unflavored <a href='/misc/dairy#whey'>whey</a>.  If you like it sweeter, add 1 tsp (5 g) <a href='https://amzn.to/3SqwsMO'>liquid monk fruit</a>.  <a href='/misc/dairy#casein'>Casein protein powder</a> is not recommended

- For a <a href='/misc/nuts#peanuts'>peanut butter</a> flavored <a href='https://amzn.to/3FduH2z'>RxBar</a>, replace the <a href='/misc/chocolate-benefits'>cocoa powder</a> with <a href='https://amzn.to/4sgDH9S'>powdered peanut butter</a> (1/2 cup, 48 g)

- Any <a href='/misc/fruit#raisins'>unsweetened dried fruit</a> will work here, not just <a href='/misc/fruit#dates'>dates</a>.  I've also made these with <a href='/misc/fruit#raisins'>raisins</a>, but <a href='/misc/fruit#fig-dried'>dried figs</a> and <a href='/misc/fruit#prune'>prunes</a> will also work just as well

- Alternatively, you can sweeten these with 4 tbsp of honey (84 g), <a href='/misc/natural-sweeteners#maple-syrup'>maple syrup</a> (80 g), or <a href='/recipes/sugar-free-syrup'>sugar free syrup</a> (80 g) instead of <a href='/misc/fruit#dates'>dates</a>
