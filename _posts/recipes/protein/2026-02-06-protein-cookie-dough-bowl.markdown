Description: Do you ever just want to eat a bowl of cookie dough with a spoon?  This recipe is the perfect edible protein cookie dough for one, and can function as either a <a href='/misc/high-protein'>high protein</a> <a href='/recipes/breakfast'>breakfast</a> or snack.  It's super high in <a href='/misc/protein'>protein</a> from the <a href='/misc/dairy#yogurt'>greek yogurt</a> and <a href='/misc/dairy#whey'>protein powder</a>, while also containing good amounts of <a href='/misc/fats'>healthy fats</a> and <a href='/misc/fiber'>fiber</a> from the <a href='/misc/nuts#almonds'>almond butter</a> and <a href='/misc/nuts#coconut'>coconut flour</a>
Instructions:
- In a <a href='https://amzn.to/4adxMft'>small bowl</a>, mix together <a href='/misc/dairy#yogurt'>yogurt</a>, <a href='/misc/nuts#almonds'>almond butter</a>, vanilla, <a href='https://amzn.to/3SqwsMO'>liquid monk fruit</a>, salt, <a href='/misc/nuts#coconut'>coconut flour</a>, and <a href='/misc/dairy#whey'>protein powder</a>. Top with <a href='/misc/chocolate-benefits'>chocolate chips</a>, and serve
Notes:
- I'm using <a href='/misc/nuts#almonds'>almond butter</a> here, but any <a href='/recipes/natural-peanut-butter'>natural nut or seed butter</a> will work, such as <a href='/misc/nuts#cashews'>cashew butter</a>, <a href='/misc/nuts#peanuts'>peanut butter</a>, <a href='/misc/seeds#sunflower-seeds'>sunflower seed butter</a>, or <a href='/misc/seeds#sesame-seeds'>tahini</a>

- If you don't mind the extra <a href='/misc/hidden-sugar'>sugar</a>, <a href='/misc/carbs'>net carbs</a>, and <a href='/misc/calories'>calories</a>, you can use <a href='/misc/natural-sweeteners#honey'>honey</a> (1/2 tbsp, 10 g) instead of <a href='https://amzn.to/3SqwsMO'>liquid monk fruit</a> as your sweetener, as well as opt for regular chocolate chips instead of the <a href='/misc/hidden-sugar'>sugar-free</a> variety
