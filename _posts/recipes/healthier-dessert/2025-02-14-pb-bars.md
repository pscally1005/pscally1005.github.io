Description: These no bake <a href='/misc/nuts#peanuts'>peanut butter</a> bars are like a simpler Reese's cup, without all the <a href='/misc/hidden-sugar'>refined sugars</a> and <a href='/misc/fats'>oils</a>.  It's so simple to make, just mix together the dough, press it into a pan, and melt some chocolate on top.  This is a <a href='/recipes/healthier-dessert'>healthier dessert</a>, but it is not a <a href='/misc/calories'>low calorie</a> <a href='/recipes/healthier-dessert'>dessert</a>, as it contains a lot of <a href='/misc/nuts#peanuts'>peanut butter</a>, so it has a lot of (healthy) <a href='/misc/fats'>fats</a> and <a href='/misc/calories'>calories</a>.  It also contains a fair bit of <a href='/misc/hidden-sugar'>sugar</a> from the honey and chocolate chips, so use <a href='/recipes/sugar-free-syrup'>sugar free syrup</a> or <a href='/recipes/monkfruit-chocolate-chunks'>sugar free chocolate chips</a> if you desire!
Instructions: 
- In a <a href='https://amzn.to/4adxMft'>medium glass bowl</a>, combine together <a href='/misc/nuts#peanuts'>peanut butter</a> and honey. Microwave for 30 seconds if necessary to make it easier to stir

- Add in the vanilla and <a href='/misc/nuts#coconut'>coconut flour</a>, and mix to form a dough. It should feel like a slightly drier cookie dough
- <img src='/assets/Food/Healthier Dessert/PB Bars/dough.jpg' alt='' class='instruction-image'>

- Line a <a href='https://amzn.to/3YY2H9q'>9" square baking pan</a> with parchment paper. Evenly press the dough into the bottom of the pan. Freeze as you prepare the topping
- <img src='/assets/Food/Healthier Dessert/PB Bars/base.jpg' alt='' class='instruction-image'>

- Wipe down your bowl, and add in the chocolate chips and <a href='/misc/nuts#peanuts'>peanut butter</a>. Melt in 20 second intervals, stirring between, until you just have a melted <a href='/misc/chocolate-benefits'>chocolate</a>
- <img src='/assets/Food/Healthier Dessert/PB Bars/melted.jpg' alt='' class='instruction-image'>

- Pour on top of the base, and evenly spread throughout. Optionally top with flaky salt.  Freeze for 1 hour to firm before slicing
- <img src='/assets/Food/Healthier Dessert/PB Bars/top.jpg' alt='' class='instruction-image'>
- <img src='/assets/Food/Healthier Dessert/PB Bars/sliced.jpg' alt='' class='instruction-image'>
Notes:
- For the base, any sort of <a href='/recipes/natural-peanunt-butter'>natural nut or seed butter</a> will work here, such as <a href='/misc/nuts#peanuts'>peanut butter</a>, <a href='/misc/nuts#almonds'>almond butter</a>, <a href='/misc/nuts#cashews'>cashew butter</a>, <a href='/misc/seeds#sunflower-seeds'>sunflower seed butter</a>, <a href='/misc/seeds#pumpkin-seeds'>pumpkin seed butter</a>, or <a href='/misc/seeds#sesame-seeds'>tahini</a>

- I've gone with honey as the sweetener here, but either maple syrup or <a href='/recipes/sugar-free-syrup'>sugar free syrup</a> will also work

- If you don't have <a href='/misc/nuts#coconut'>coconut flour</a>, then you can swap it for either <a href='/misc/grains#oats'>oat flour</a> or <a href='/misc/nuts#almonds'>almond flour</a>.  Since <a href='/misc/nuts#coconut'>coconut flour</a> absorps a lot of moisture (see <a href='/misc/water-absorption'>Water Absorption of Different Flours</a>), you may need double the amount.  Mix in the flour, and go based on feel.  You should be able to roll the dough into balls without it being too wet or dry

- For the topping, again any sort of <a href='/recipes/natural-peanunt-butter'>natural nut or seed butter</a> can work here in place of <a href='/misc/nuts#peanuts'>peanut butter</a>.  To make it <a href='/misc/hidden-sugar'>sugar free</a>, use <a href='/recipes/monkfruit-chocolate-chunks'>sugar free chocolate chips</a> or <a href='/recipes/monkfruit-chocolate-chunks'>Monk Fruit Chocolate Chunks</a> in place of standard <a href='/misc/chocolate-benefits'>chocolate chips</a>
