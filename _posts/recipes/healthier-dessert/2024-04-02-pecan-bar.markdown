Description: These bars are an adapted version of the Pecan Butter Chocolate Truffles from the cookbook Run Fast Eat Slow. I've made them into bars here, but if you have mini muffin liners you can totally make them into Reese's cups as well. This is admittedly unnecessary boujee with the <a href='/misc/nuts#pecans'>pecan butter</a> and <a href='https://amzn.to/4rhYDwh'>carob powder</a>; you can easily swap those for regular <a href='/misc/chocolate-benefits'>cocoa powder</a> and any kind of <a href='/recipes/natural-peanut-butter'>nut or seed butter</a> you like.
Instructions:
- In a <a href='https://amzn.to/4q0AUjI'>food processor</a>, blend the <a href='/misc/nuts#pecans'>pecans</a> until a smooth <a href='/misc/nuts#pecans'>pecan butter</a> forms, scraping down the sides every minute or so. This can take about 5 minutes, depending on your <a href='https://amzn.to/4q0AUjI'>food processor</a>
- <img src='/assets/Food/Healthier Dessert/Pecan Bar/pecan-bar-1.jpg' alt='' class='instruction-image'>

- Add in the rest of the filling ingredients - <a href='/misc/nuts#coconut'>coconut flour</a>, <a href='/misc/fruit#banana'>banana</a>, cinnamon, and salt. Blend until smooth and thick
- <img src='/assets/Food/Healthier Dessert/Pecan Bar/pecan-bar-2.jpg' alt='' class='instruction-image'>

- Transfer to a parchment lined <a href='https://amzn.to/3YY2H9q'>9" square pan</a>, and evenly spread the mixture with a <a href='https://amzn.to/40F2aK0'>silicone spatula</a>. Freeze for 10 minutes to harden
- <img src='/assets/Food/Healthier Dessert/Pecan Bar/pecan-bar-3.jpg' alt='' class='instruction-image'>

- In a <a href='https://amzn.to/4adxMft'>small bowl</a>, melt <a href='/misc/nuts#coconut'>coconut oil</a> in the microwave for about a minute, Stir in <a href='https://amzn.to/4rhYDwh'>carob powder</a> and salt

- Spread the melted <a href='/misc/chocolate-benefits'>chocolate</a> on top of the filling, spreading edge to edge. Refrigerate for a few hours to harden before slicing
- <img src='/assets/Food/Healthier Dessert/Pecan Bar/pecan-bar-5.jpg' alt='' class='instruction-image'>

- Slice, transfer to a parchment lined <a href='https://amzn.to/45sRAsB'>cookie sheet</a>, and flash freeze until solid.  Store in the freezer or fridge
- <img src='/assets/Food/Healthier Dessert/Pecan Bar/pecan-bar-6.jpg' alt='' class='instruction-image'>
Notes:
- Any kind of <a href='/misc/nuts'>nuts</a> can be used here - <a href='/misc/nuts#peanuts'>peanuts</a>, <a href='/misc/nuts#pistachios'>pistachios</a>, <a href='/misc/nuts#almonds'>almonds</a>, or even <a href='/misc/seeds#sunflower-seeds'>sunflower</a> or <a href='/misc/seeds#pumpkin-seeds'>pumpkin seeds</a> to make it <a href='/misc/nuts'>nut</a>-free

- Optionally, add some sweetener if you desire, such as <a href='https://amzn.to/3SqwsMO'>liquid monk fruit</a>, <a href='https://amzn.to/4ceFnvP'>granulated monk fruit</a>, or <a href='/recipes/sugar-free-syrup'>sugar free syrup</a>. <a href='https://amzn.to/4rhYDwh'>Carob</a> is mildly sweet, so I don't find any necessary, but you may want some if you use <a href='/misc/chocolate-benefits'>cocoa powder</a> instead
