Description: This sweet, sour, and spicy tropical fruit salsa is perfect topping for <a href='/recipes/fajitas'>Chicken Fajitas with Peppers</a>. It features finely diced <a href='/misc/fruit#pineapple'>pineapple</a>, <a href='/misc/fruit#mangos'>mango</a>, and <a href='/misc/veggies#onion'>red onion</a>, flavored with <a href='/recipes/hot-sauce'>hot sauce</a>, <a href='/misc/fruit#lime-juice'>lime juice</a>, and a <a href='/recipes/italian-dressing'>Homemade Sugar Free Italian Dressing</a>.
Instructions:
- Finely dice your <a href='/misc/fruit#pineapple'>pineapple</a>, <a href='/misc/fruit#mangos'>mango</a>, and <a href='/misc/veggies#onion'>onion</a>, and add to a <a href='https://amzn.to/4adxMft'>large bowl</a>

- Mix with the remaining ingredients - <a href='/recipes/italian-dressing'>Italian dressing</a>, <a href='/recipes/hot-sauce'>hot sauce</a>, <a href='/misc/fruit#lime-juice'>lime juice</a>, cilantro (or parsley), thyme, allspice, nutmeg, and cinnamon
