Description: This healthy tuna salad, or tuna fish, uses a base of <a href='/misc/fruit#avocado'>avocado</a> instead of <a href='/misc/fake-healthy-foods#dips'>mayonnaise</a>. That means it's significantly lower in <a href='/misc/fats'>fat</a> and <a href='/misc/calories'>calories</a>, and the quality of <a href='/misc/fats'>fat</a> is much higher. <a href='/misc/fruit#avocado'>Avocados</a> are high in <a href='/misc/fats'>heart healthy mono unsaturated fats</a>, as opposed to <a href='/misc/fake-healthy-foods#dips'>mayo</a>, which is nothing but empty <a href='/misc/calories'>calorie</a> inflammatory <a href='/misc/fake-healthy-foods#seed-oil'>seed oils</a>. With <a href='/misc/fish#tuna'>tuna</a> canned in water, this <a href='/misc/high-protein'>high protein</a> dish can be used as a sandwich filling, <a href='/salad'>salad</a> topper, or even a dip for raw <a href='/misc/veggies'>vegetables</a>.  For a <a href='/misc/dairy#yogurt'>Greek yogurt</a> based tuna salad, check out my <a href='/recipes/tuna-salad'>No-Mayo Tuna Salad</a>.
Instructions:
- Cut your <a href='/misc/veggies#onion'>onion</a> into a fine dice, and add to a <a href='https://amzn.to/4adxMft'>medium bowl</a>. Add the <a href='/misc/fruit#avocado'>avocado</a> to the bowl, and mash with the back of a fork. Drain your <a href='/misc/fish#tuna'>tuna</a>, and add to the bowl with the rest of the ingredients. Mix until fully combined
