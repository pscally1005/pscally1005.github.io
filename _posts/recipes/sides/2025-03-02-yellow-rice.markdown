Description: Am I the only one who used to think that yellow rice was a different type of <a href='/misc/grains#brown-rice'>rice</a>? Turns out, it's just <a href='/misc/grains#brown-rice'>rice</a> with turmeric. Here, I'm using <a href='/misc/grains#brown-rice'>brown rice</a> instead of <a href='/misc/grains#white-rice'>white</a> for more <a href='/misc/fiber'>fiber</a> and <a href='/misc/nutrient-alphabet'>micronutrients</a>. Turmeric, the main feature of this <a href='/recipes/sides'>side</a>, is often regarded as one of the best spices for <a href='/misc/chronic-inflammation'>reducing inflammation</a>. My version is a little darker due to the addition of other <a href='/misc/chronic-inflammation'>anti-inflammatory</a> spices, like cayenne, paprika, cinnamon, black pepper, and <a href='/misc/veggies#ginger'>ginger</a>.
Instructions:
- Add all ingredients to a <a href='https://amzn.to/46ccg8m'>medium pot</a> over high heat. Cover and bring to a boil, reduce heat to medium, and let simmer for 20-25 minutes until all water has been absorbed.  Garnish with dried parsley
Notes:
- I've never tried, but I see no reason why this wouldn't also work with <a href='/misc/beans#red-lentils'>red lentils</a> or <a href='/misc/grains#quinoa'>quinoa</a>, which would both be higher in <a href='/misc/protein'>protein</a> and <a href='/misc/fiber'>fiber</a> than <a href='/misc/grains#brown-rice'>brown rice</a>.  Screw it, make yellow <a href='/misc/grains#oats'>oats</a>, I don't make the rules
