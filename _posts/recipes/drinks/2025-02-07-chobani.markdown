Description: I recently had one of those <a href='https://amzn.to/3FnzL4r'>Chobani Yogurt Drinks</a>, and it was a pretty good <a href='/misc/dairy#yogurt'>yogurt</a> <a href='/recipes/drinks'>drink</a> with 20 grams of <a href='/misc/protein'>protein</a>, no <a href='/misc/hidden-sugar'>added sugar</a>, and mostly clean ingredients.  But at $2.50 per serving, I knew I could make it cheaper myself.  So that's what I did today.  This one is <a href='/misc/fruit#strawberries'>strawberry</a> flavored, uses <a href='https://amzn.to/3SqwsMO'>liquid monk fruit</a> as the sweetener, and is half the price!
Instructions:
- Add all ingredients to a <a href='https://amzn.to/4bO4VQ3'>blender</a>, and blend until smooth. Optionally, add a serving of <a href='https://amzn.to/43ycqF2'>lactase enzyme</a> if you're lactose intolerant (or take a lactose pill)
Notes:
- You can replace the <a href='/misc/dairy#skim-milk'>skim milk</a> and <a href='/misc/nuts#coconut'>coconut oil</a> with 1/4 cup (60 g) <a href='/misc/dairy#whole-milk'>whole milk</a> for the same <a href='/misc/fats'>fat</a> and <a href='/misc/calories'>calories</a>. <a href='/misc/olive-oil'>Extra virgin olive oil</a> will also work in place of <a href='/misc/nuts#coconut'>coconut oil</a>
