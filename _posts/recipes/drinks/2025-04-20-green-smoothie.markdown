Description: I used to be big into <a href='/recipes/smoothie'>smoothies</a> in high school in college, but have gone on a hiatus for a couple of years.   After my <a href='/recipes/sleepy-smoothie'>Golden Milk, aka Sleepy Smoothie</a> though, I was craving a green <a href='/recipes/smoothie'>smoothie</a>.  <a href='/misc/fruit#banana'>Bananas</a> are naturally sweet, and are a good source of <a href='/misc/nutrient-alphabet#B'>Vitamin B6</a> and <a href='/misc/potassium'>potassium</a>.  <a href='/misc/fruit#mandarin'>Mandarin oranges</a> are also sweet, and provide <a href='/misc/vitamin-c'>Vitamin C</a>.  It contains <a href='/misc/fats'>healthy fats</a>, <a href='/misc/magnesium'>magnesium</a>, <a href='/misc/nutrient-alphabet#M'>manganese</a>, and <a href='/misc/potassium'>potassium</a> from the <a href='/misc/seeds#hemp-seeds'>hemp seeds</a>.  <a href='/misc/veggies#spinach-fresh'>Spinach</a> is rich in <a href='/misc/fiber'>fiber</a>, <a href='/misc/nutrient-alphabet#A'>vitamins A</a>, <a href='/misc/nutrient-alphabet#F'>B9</a>, <a href='/misc/nutrient-alphabet#E'>E</a>, and <a href='/misc/nutrient-alphabet#K'>K</a>, as well as <a href='/misc/iron'>iron</a>.  This nutritious <a href='/recipes/drinks'>drink</a> is a great pairing to some <a href='/misc/protein'>protein</a> for <a href='/recipes/breakfast'>breakfast</a> (or add a scoop of <a href='/misc/dairy#whey'>protein powder</a>).
Instructions:
- The night before, break your <a href='/misc/fruit#banana'>banana</a> into chunks, and freeze in an airtight bag. You can also use 1 cup (150 g) frozen <a href='/misc/fruit#grapes'>grapes</a> in place of <a href='/misc/fruit#banana'>banana</a>

- The next morning, blend together all ingredients until smooth
Notes:
- Optionally, add a scoop of <a href='/misc/dairy#whey'>protein powder</a>. You can also use whatever <a href='/misc/dairy#skim-milk'>milk</a> you have on hand; today was <a href='/misc/nuts#almonds'>almond</a> for me
