Description: Summer is winding down, but there's still enough time for some cool and refreshing <a href='/recipes/drinks'>drinks</a>.  Today is a simple limeade made with fresh squeezed <a href='/misc/fruit#lime-juice'>lime juice</a> and <a href='https://amzn.to/3SqwsMO'>liquid monk fruit</a>.  This <a href='/misc/hidden-sugar'>sugar free</a> and <a href='/misc/calories'>low calorie</a> refreshing treat is perfect for a hot summer day without spiking <a href='/misc/diabetes'>blood sugar</a>.
Instructions:
- Shake together all ingredients in an airtight container. Refrigerate for up to 1 week
Notes:
- I'm making limeade today, but you can obviously make lemonade instead with <a href='/misc/fruit#lemon-juice'>lemon juice</a> instead of <a href='/misc/fruit#lime-juice'>lime juice</a>

- Fresh squeezed <a href='/misc/fruit#lime'>limes</a> (or <a href='/misc/fruit#lemon'>lemons</a>) are recommended.  If you are to use bottled though, opt for a <a href='/misc/fruit#lime'>lime</a> (or <a href='/misc/fruit#lemon'>lemon</a>) juice that is 100% juice not from concentrate

- This limeade is <a href='/misc/hidden-sugar'>sugar free</a>, being sweetened with <a href='https://amzn.to/3SqwsMO'>liquid monk fruit</a>.  A <a href='https://amzn.to/4enTf6c'>standard limeade</a> or <a href='https://amzn.to/4a5ULZB'>lemonade sweetened with sugar</a> would have 110 <a href='/misc/calories'>calories</a> with 27 g of <a href='/misc/hidden-sugar'>added sugar</a> per 1 cup (240 g)
