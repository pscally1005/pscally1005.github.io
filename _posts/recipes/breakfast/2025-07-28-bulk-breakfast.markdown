Description: This recipe is great for those looking to pack on some muscle, or for those with a <a href='/misc/high-protein'>high protein</a> and <a href='/misc/calories'>calorie</a> intake. With 1,000 <a href='/misc/calories'>calories</a> and 100 g of <a href='/misc/protein'>protein</a>, this <a href='/recipes/breakfast'>breakfast</a> is a <a href='/misc/protein'>protein</a> bomb with a lot of <a href='/misc/fats'>healthy fats</a> and good <a href='/misc/carbs'>carbs</a> as well.
Instructions:
- In a <a href='https://amzn.to/4adxMft'>medium bowl</a> or airtight container, mash one of your <a href='/misc/fruit#banana'>bananas</a> with the back of a fork. Mix in the <a href='/misc/dairy#yogurt'>yogurt</a>, <a href='/recipes/natural-peanut-butter'>nut butter</a>, <a href='/misc/dairy#whey'>protein powder</a>, and <a href='https://amzn.to/4sgDH9S'>powdered peanut butter</a>. Cut your other <a href='/misc/fruit#banana'>banana</a> into slices, and add on top. Eat immediately, or cover and refrigerate overnight
- <img src='/assets/Food/Breakfast/Bulk/cover-1.jpg' alt='' class='instruction-image'>
Notes:
- If you need more (or less) <a href='/misc/protein'>protein</a>, <a href='/misc/fats'>fat</a>, and <a href='/misc/carbs'>carbs</a>, the amounts can easily be adjusted.  Add more <a href='/misc/dairy#yogurt'>yogurt</a>, <a href='/misc/dairy#whey'>protein powder</a>, or <a href='https://amzn.to/4sgDH9S'>powdered peanut butter</a> for additional <a href='/misc/protein'>protein</a> to aid in satiation and muscle recovery.  Go for <a href='/misc/dairy#yogurt-whole-milk'>whole milk Greek yogurt</a> or more <a href='/misc/nuts#peanuts'>peanut butter</a> for <a href='/misc/fats'>healthy fats</a> to meet your <a href='/misc/calories'>calorie</a> goal.  You can also mash in extra <a href='/misc/fruit#banana'>bananas</a> or stir in some <a href='/misc/grains#oats'>rolled oats</a> for more <a href='/misc/carbs'>carbs</a>, <a href='/misc/fiber'>fiber</a>, and quick bursts of energy.

- This is really a blank slate.  Top it with some <a href='/misc/fruit#blueberries'>berries</a>, mix in some <a href='/misc/grains#oats'>oats</a> or <a href='/misc/fruit#dates'>date</a> paste, swap the <a href='/misc/nuts#peanuts'>peanut butter</a> for another <a href='/recipes/natural-peanut-butter'>nut butter</a>, try different flavors of <a href='/misc/dairy#whey'>protein powder</a>, mix in <a href='/misc/chocolate-benefits'>cocoa powder</a> or cinnamon for more flavor; the options are endless!

- Any sort of natural <a href='/misc/nuts'>nut</a> or <a href='/recipes/natural-peanut-butter'>seed butter</a> will work, like <a href='/misc/nuts#peanuts'>peanut</a>, <a href='/misc/nuts#almonds'>almond</a>, <a href='/misc/nuts#cashews'>cashew</a>, <a href='/misc/nuts#pistachios'>pistachio</a>, <a href='/misc/nuts#walnuts'>walnut</a>, <a href='/misc/seeds#sunflower-seeds'>sunflower seed</a>, <a href='/misc/seeds#pumpkin-seeds'>pumpkin seed</a>, <a href='/misc/seeds#sesame-seeds'>tahini</a>, etc. Just make sure to buy (or make) any <a href='/recipes/natural-peanut-butter'>nut butter</a> with just roasted <a href='/misc/nuts'>nuts</a> and salt, without any <a href='/misc/fats'>hydrogenated oils</a> or <a href='/misc/hidden-sugar'>added sugars</a>

- I'm using vanilla <a href='/misc/dairy#whey'>whey</a> here, but chocolate or any other flavor will do as well. You can also use <a href='/misc/dairy#casein'>casein</a> instead of <a href='/misc/dairy#whey'>whey</a>, but you need to add some more liquid (like water, <a href='/misc/dairy#skim-milk'>milk</a>, or <a href='/misc/dairy#almond-milk'>non-dairy milk</a>) since <a href='/misc/dairy#casein'>casein</a> <a href='/misc/water-absorption'>absorbs much more liquid</a> than <a href='/misc/dairy#whey'>whey</a>

- An unflavored <a href='/misc/dairy#whey'>protein powder</a> will also work, just add some additional sweetener and flavoring. I'd go with 1/2 tsp (2.5 g) vanilla or almond extract, along with one of the following sweetener options
- INGREDIENTS(sweeteneroptions)

- To make this a non-bulking <a href='/recipes/breakfast'>breakfast</a>, keep the <a href='/misc/dairy#yogurt'>yogurt</a> the same, and halve the rest of the ingredients.  The recipe would then be the following
- INGREDIENTS(nonbulkbreakfast)
