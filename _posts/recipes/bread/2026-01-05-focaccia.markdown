Description: |
  This <a href='/misc/celiac'>gluten free</a> <a href='/misc/nuts#almonds</a>almond flour</a> focaccia <a href='/recipes/bread'>bread</a> is high in <a href='/misc/fats'>healthy fats</a> and low in <a href='/misc/carbs'>net carbs</a>.  Featuring <a href='/misc/nuts#almonds'>almond flour</a> instead of <a href='/misc/grains#white-wheat'>white flour</a>, this bread is a good source of <a href='/misc/fats'>healthy fats</a>, <a href='/misc/fiber'>fiber</a>, and <a href='/misc/nutrient-alphabet#E'>vitamin E</a>, all with only 3 g of <a href='/misc/carbs'>net carbs</a> per slice.<br><br>

  It's simple to put together, and contains no <a href='/misc/fats'>added oil</a>, unlike most focaccia recipes.  For similar <a href='/misc/nuts#almonds'>almond flour</a> and <a href='/misc/dairy#mozzarella'>mozzarella cheese</a> <a href='/recipes/bread'>bread recipes</a>, see my <a href='/recipes/gluten-free-pretzels'>Gluten Free Savory Pretzels</a> and <a href='/recipes/almond-flour-empanadas'>Almond Flour Empanadas</a>.
Instructions:
- Preheat your oven to 350F. Line a <a href='https://amzn.to/3YY2H9q'>9" square baking dish</a> with parchment paper, and <a href='https://amzn.to/3Hdg0gk'>lightly grease the paper with oil</a>

- Add the <a href='/misc/dairy#mozzarella'>mozzarella</a> to a <a href='https://amzn.to/4zyFnzN'>large glass bowl</a>. Cut the <a href='/misc/dairy#cream-cheese'>cream cheese</a> into cubes, and add on top. Microwave for 1 minute, stirring halfway with a <a href='https://amzn.to/40F2aK0'>silicone spatula</a>
- <img src='/assets/Food/Bread/Almond Flour Focaccia/cheese.jpg' alt='' class='instruction-image'>

- Mix in the baking powder and <a href='/misc/meat#eggs'>egg</a> with a <a href='https://amzn.to/40F2aK0'>silicone spatula</a>. Mix in the <a href='/misc/nuts#almonds'>almond flour</a>, and combine with the <a href='https://amzn.to/40F2aK0'>spatula</a>. Switch to your hands, and knead until fully combined.  The dough should be slightly sticky
- <img src='/assets/Food/Bread/Almond Flour Focaccia/dough.jpg' alt='' class='instruction-image'>

- Press the dough to the baking dish. Make dimples in the dough with your fingers. Top with rosemary and salt, and lightly press them into the dough. Optionally <a href='https://amzn.to/3Hdg0gk'>spray</a> the top with <a href='/misc/olive-oil'>olive oil</a>
- <img src='/assets/Food/Bread/Almond Flour Focaccia/raw.jpg' alt='' class='instruction-image'>

- Bake at 350F until puffed and lightly golden brown, about 20 minutes.  Transfer to a wire rack, and allow it to cool totally before cutting into 9 slices
- <img src='/assets/Food/Bread/Almond Flour Focaccia/cut.jpg' alt='' class='instruction-image'>
Notes:
- For a lower <a href='/misc/fats'>fat</a> version, use <a href='/misc/fats'>fat free</a> <a href='/misc/dairy#mozzarella'>mozzarella cheese</a> (1 1/2 cup, 168 g) and <a href='/misc/dairy#yogurt'>plain nonfat greek yogurt</a> (2 tbsp, 28 g) in place of the standard <a href='/misc/dairy#mozzarella'>shredded mozzarella cheese</a> and <a href='/misc/dairy#cream-cheese'>cream cheese</a>

- To make it <a href='/misc/nuts'>nut</a> free, swap the <a href='/misc/nuts#almonds'>almond flour</a> for <a href='/misc/grains#oats'>oat flour</a> (1 1/2 cup, 135 g), though it will be a little drier due to the lack of <a href='/misc/fats'>fat</a> from the <a href='/misc/nuts#almonds'>almonds</a>

- You can also use <a href='/misc/nuts#coconut'>coconut flour</a> instead to make it <a href='/misc/nuts'>nut</a> free (3/4 cup, 90 g)

- You can even get away with using <a href='/misc/dairy#whey'>whey protein powder</a> (4 scoops, 120 g) or <a href='https://amzn.to/4sgDH9S'>powdered peanut butter</a> (1 cup, 96 g) in this "focaccia" if you're into that

- Try whatever <a href='/misc/dairy#mozzarella'>cheese</a> you like!  I've made this quite a few times with <a href='/misc/dairy#mozzarella'>mozzarella</a> as directed, but I've also has great success using <a href='/misc/dairy#cheddar'>cheddar</a>, <a href='/misc/dairy#feta'>feta</a>, and even <a href='/misc/dairy#brie'>brie</a>!

- For a <a href='/misc/dairy#grated-cheese'>parmesan</a> variant, keep the <a href='/misc/dairy#mozzarella'>mozzarella</a>, and replace the <i><a href='/misc/nuts#almonds'>almond flour</a></i> with <a href='/misc/dairy#grated-cheese'>grated parmesan cheese</a> (1 1/2 cup, 180 g).  You can do the same with <a href='https://amzn.to/43wLkhB'>nutritional yeast</a> too (1 1/2 cup, 120 g).  Either regular <a href='/misc/dairy#mozzarella'>mozzarella</a> or <a href='/misc/fats'>fat free</a> <a href='/misc/dairy#mozzarella'>mozzarella</a> will work here.

- |
  For a vegan variation, use the following ingredients below.<br><br>

  The <a href='/misc/dairy#mozzarella'>mozzarella</a>, <a href='/misc/dairy#cream-cheese'>cream cheese</a>, and <a href='/misc/meat#eggs'>egg</a> are replaced with <a href='/misc/fruit#apple'>unsweetened applesauce</a>.  Salt is added to the dough to account for the lack of the salty <a href='/misc/dairy#mozzarella'>cheese</a>.<br><br>

  I'm calling for <a href='/misc/nuts#almonds'>almond flour</a> here (1 1/2 cup, 168 g), but you can also use <a href='/misc/grains#oats'>oat flour</a> (1 1/2 cup, 135 g), <a href='/misc/nuts#coconut'>coconut flour</a> (3/4 cup, 90 g), <a href='/misc/dairy#whey'>whey protein</a> (4 scoops, 120 g), or <a href='https://amzn.to/4sgDH9S'>powdered peanut butter</a> (1 cup, 96 g).  Obviously if you use <a href='/misc/dairy#whey'>whey</a> it won't be vegan, but it will be <a href='/misc/meat#eggs'>egg</a> and <a href='/misc/dairy#mozzarella'>cheese</a> free.<br><br>

  No microwaving required.  Just mix together the ingredients in a <a href='https://amzn.to/4zyFnzN'>large bowl</a>, add to the pan, and top with rosemary and flaky salt.<br><br>

  Bake for <b>30 minutes</b> this time at 350F (as opposed to 20 minutes), or until the top is set, the edges are lightly browned, and the <a href='https://amzn.to/4kmobG2'>internal temperature</a> is around <a href='https://amzn.to/4kmobG2'>205F</a>.  The dough is a bit wetter, so it will need a little more time to bake.
- INGREDIENTS(veganfocaccia)
