Description: As someone who loves both <a href='/misc/dairy#cottage-cheese'>cottage cheese</a> and <a href='/misc/nuts#peanuts'>peanut butter</a>, this <a href='/misc/high-protein'>high protein</a> spread helps curb any <a href='/misc/nuts#peanuts'>peanut butter</a> cravings.  It's blended together <a href='https://amzn.to/4sgDH9S'>powdered peanut butter</a>, <a href='/misc/dairy#cottage-cheese'>cottage cheese</a>, and <a href='/misc/fruit#banana'>banana</a>, for a delicious <a href='/misc/nuts#peanuts'>peanut</a> flavored spread for my <a href='/yogurt'>morning yogurt</a>. For the same serving, there is only 1/4 of the <a href='/misc/calories'>calories</a>, and over twice the amount of <a href='/misc/protein'>protein</a> per 100 <a href='/misc/calories'>calories</a>.  You can also check out any of my other <a href='/nut-butter'>nut butter recipes</a>!
Instructions:
- Blend together <a href='/misc/dairy#cottage-cheese'>cottage cheese</a>, <a href='https://amzn.to/4sgDH9S'>powdered peanut butter</a>, overripe <a href='/misc/fruit#banana'>banana</a>, cinnamon, and almond extract in a <a href='https://amzn.to/3VHhgMM'>small food processor</a>.  Transfer to an airtight container, and store in the fridge.  Optionally garnish with <a href='/misc/nuts#peanuts'>peanuts</a> and <a href='/misc/beans#chickpeas'>chickpeas</a> as I did here
Notes:
- Pureed <a href='/misc/beans#chickpeas'>chickpeas</a> can be used instead of <a href='/misc/dairy#cottage-cheese'>cottage cheese</a>, but you will want to add about 1/2 cup (120 g) of <a href='/misc/dairy#almond-milk'>unsweetened almond milk</a> and 1/4 tsp (1.5 g) salt.  This makes 18 servings of 2 tbsp (31 g), as compared to 13 servings of 2 tbsp (31 g) each for the <a href='/misc/dairy#cottage-cheese'>cottage cheese</a> variation.
